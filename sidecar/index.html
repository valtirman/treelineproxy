Sidecar MITM

Drop‑in TLS MITM for GenAI egress. Policy + DLP + risk scoring with zero app changes.

Get StartedDownload Compose

Local‑only defaults (127.0.0.1). macOS/Linux/WSL.

3‑command install

curl -fsSL https://treelineproxy.io/downloads/compose.quickstart.yml -o compose.yml
docker compose -f compose.yml up -d
curl -fsSL https://treelineproxy.io/downloads/smoke.sh -o smoke.sh && chmod +x smoke.sh && ./smoke.sh

Observability

Prom/Grafana overlay:

docker compose -f compose.yml -f https://treelineproxy.io/downloads/compose.observability.yml up -d

Security defaults

Decision headers OFF by default. Use metrics/logs in prod; enable headers only for local debug.

TREELINE_DECISION_HEADERS=true docker compose -f compose.yml up -d
