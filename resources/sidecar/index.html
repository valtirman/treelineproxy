Overview

Drop-in HTTP(S)/TLS MITM for AI/API egress. Enforces policy (allow/redact/block), emits telemetry (JSONL, Prometheus). Zero app changes.

Quickstart (Docker Compose)

services:
  sidecar:
    image: ghcr.io/<org>/sidecar@sha256:<PIN>
    ports: ["127.0.0.1:15050:15000","127.0.0.1:9096:9095","127.0.0.1:18080:8080"]
    environment:
      POLICY_DIR: /policies
      LOG_PATH: /data/telemetry.jsonl
      FAIL_MODE: closed
      DECISION_HEADERS: "false"
    volumes:
      - ./policies:/policies:ro
      - ./data:/data
      - ./mitm:/home/mitmproxy
    healthcheck:
      test: ["CMD","curl","-fsS","http://localhost:8080/health"]
      interval: 10s
      timeout: 3s
      retries: 10
  policy_engine:
    image: ghcr.io/<org>/policy-engine@sha256:<PIN>
    environment: { POLICY_DIR: /policies }
    volumes: [ "./policies:/policies:ro" ]

Smoke:

export PROXY=http://127.0.0.1:15050
curl -i -x "$PROXY" -k https://httpbin.org/anything -H 'Authorization: Bearer x' -d hi -o /dev/null -w "%{http_code}\n"   # expect 403
curl -s -x "$PROXY" -k https://postman-echo.com/post -H 'content-type: text/plain' \
  --data 'email a@b.com SSN 123-45-6789 CC 4242 4242 4242 4242' | jq -r '.data'    # expect redactions

Kubernetes (sidecar)

containers:
- name: app
  env:
    - name: HTTP_PROXY
      value: http://localhost:15000
    - name: HTTPS_PROXY
      value: http://localhost:15000
    - name: NO_PROXY
      value: 127.0.0.1,localhost,.svc,.cluster.local
- name: treeline
  image: ghcr.io/<org>/sidecar@sha256:<PIN>
  env:
    - name: POLICY_DIR
      value: /policies
    - name: FAIL_MODE
      value: closed
    - name: DECISION_HEADERS
      value: "false"
  ports: [{containerPort:15000,name:"proxy"}]

TLS Interception & CA

# Ubuntu/Debian
sudo cp mitmproxy-ca-cert.pem /usr/local/share/ca-certificates/treeline.crt
sudo update-ca-certificates

Configuration

  • POLICY_DIR, LOG_PATH, FAIL_MODE=closed
  • DECISION_HEADERS=false (debug-only toggle)
  • Optional: token caps; OTEL_EXPORTER_OTLP_ENDPOINT

Policy Pack (Baseline v1) — excerpt

rules:
- id: r107_aws_keys
  match: regex
  action: block
  pattern: '(AKIA[0-9A-Z]{16}|ASIA[0-9A-Z]{16})'
- id: r103_email
  match: regex
  action: redact
  pattern: '[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}'
  redact_with: '<redacted:email>'

Observability

scrape_configs:

Decision Headers (Debug)

Default OFF to avoid policy intel leakage. Use logs/metrics in prod.

Troubleshooting

  • Port in use → change host ports or stop conflicts
  • No body redaction → install CA
  • Headers “missing” → expected (debug OFF)

Release Checklist

  • Compose quickstart runs macOS/Linux/WSL
  • ECS task behind ALB; /health 200
  • Prometheus/Grafana visible
  • Baseline v1 + exceptions present
  • Docs pin GHCR digests
