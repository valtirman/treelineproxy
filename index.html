How Treeline works

  1. Intercept — Transparent HTTP(S) proxy (sidecar/gateway).
  2. Inspect — Match rules: PII/DLP, secrets, JWTs, jailbreaks, exfil; optional semantic checks.
  3. Decide — allow / redact / block (fail-open or fail-closed).
  4. Observe — Export metrics/logs/traces and alert on policy hits.

Policy packs ship ready-to-use and are fully tunable for your risk appetite.

Quickstart (copy/paste)

curl -fsSL https://treelineproxy.io/downloads/compose.quickstart.yml -o compose.yml
docker compose -f compose.yml up -d
curl -fsSL https://treelineproxy.io/downloads/smoke.sh -o smoke.sh && chmod +x smoke.sh && ./smoke.sh

Expect: /ready → LIVE, header/key blocks → 403, body redactions → [REDACTED], metrics at 127.0.0.1:9096/metrics.
